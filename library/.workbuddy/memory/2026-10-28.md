## 本轮交付：安全响应头 + 缓存策略加固（`web.py`）

### 背景
全栈专家「生产加固」要求包含安全头。审计发现已有 nosniff / X-Frame-Options / Referrer-Policy / CSP，
但缺少 Permissions-Policy、Cross-Origin-* 隔离头，且**所有响应无 Cache-Control**——API 响应含 JWT/令牌，不应被缓存。

### 改动（仅 `web.py`）
- `_SECURITY_HEADERS` 新增：
  - `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=()`
  - `Cross-Origin-Opener-Policy: same-origin`
  - `Cross-Origin-Resource-Policy: same-origin`
- `_emit_common_headers(handler, cache="no-store")`：新增 cache 参数并发送 `Cache-Control`。
  - JSON / CSV / OPTIONS / ready 默认 `no-store`（令牌、审计等敏感响应禁止缓存）。
  - `_serve_homepage` 传 `cache="no-cache"`（首页可缓存但每次回源校验，便于前端更新生效）。
- 说明：HSTS 未加（本地 HTTP 演示无意义，且浏览器仅 HTTPS 下生效），CSP 因单文件内联脚本保留 `'unsafe-inline'`。
