## 本轮交付：集中配置模块（12-factor）

### 新增 `core/config.py`
- `_load_dotenv(path=".env")`：手动解析 KEY=VALUE，跳过空行/`#`/无`=`行，去值两侧引号，不覆盖已存在的真实环境变量。导入时即调用 `_load_dotenv()`，使 `os.environ.get` 可读到 `.env` 值。
- `class ConfigError`：配置非法 → 启动快速失败（fail-fast）。
- `_int(name, default, min_value=None)`：读整型；缺省用 default；非法/越界抛 `ConfigError`。
- 集中定义：`JWT_SECRET`(不安全默认密钥 `_INSECURE_DEFAULT_SECRET`，本地演示用)、`ACCESS_TTL=1800`(≥1)、`REFRESH_TTL=604800`(≥1)、`RATE_LIMIT=600`(≥1)、`RATE_WINDOW=60`(≥1)、`CORS_ORIGINS`（逗号分隔解析，空=拒绝跨域）。
- `is_secret_insecure()` / `validate()`：返回非致命告警列表（默认密钥 / 空 CORS），不抛异常。

### 改造 `web.py`
- 删除 116-123 行内联配置块，改为 `from core.config import (JWT_SECRET, ACCESS_TTL, REFRESH_TTL, RATE_LIMIT, RATE_WINDOW, CORS_ORIGINS as _CORS_ORIGINS)`。
- `run()` 注册 `from core import config` + `for _w in config.validate(): print("⚠️  配置告警：", _w)`，在 serve_forever 前打印告警。
