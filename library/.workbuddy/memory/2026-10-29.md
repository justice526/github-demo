### 新增 `core/migrations.py`（零第三方依赖）
- `schema_migrations(version PK, description, applied_at)` 记录已应用版本。
- `Migration(version, description, up, down)`；`MIGRATIONS` 按版本升序。
- `apply_all()`：跳过已应用，逐个在**独立事务**中执行 up 并登记版本；幂等。
- `rollback_to(target)`：倒序回滚 version > target 的迁移（down + 删除登记）；空串表示全部回滚。
- `status()` / `applied_versions()`：**只读**，不创建任何表（`_table_exists` 先判存在）。
- CLI：`python -m core.migrations status|apply|rollback <版本|''>`。
- 迁移 0001 = 基线（11 张表 `CREATE TABLE IF NOT EXISTS`，对既有库幂等；down 按依赖倒序删表）。
- 迁移 0002 = 为 borrow_record 建 `idx_borrow_user` / `idx_borrow_book`（down 删索引）。
- DDL 内联在本模块（迁移是 schema 的不可变快照），不从 repository 反向引用，守住 core 分层。
