# 2026-10-12 工作日志

## 生产加固（JWT + 刷新令牌 + CORS + 限流 + 安全头）

完成 web.py 认证体系从「内存 token」到「JWT 短时效访问令牌 + 服务端刷新令牌」的改造，并补齐防护。

### 新增文件
- `core/jwt.py`：纯标准库 HS256（hmac+sha256），`encode/decode`，恒定时间签名比较防时序攻击，带 iat/exp。
- `repository/refresh_token_repo.py`：`refresh_token(token PK, user_id, expires_at, created_at)` 表；
  `init_table/create/validate/revoke/revoke_all`，支持轮换与吊销。

### 修改
- `core/errors.py`：新增 `RateLimitError`（→ 429），`HTTP_STATUS` 与 `__all__` 同步。
- `web.py`：
  - 导入时幂等建 `tag`/`book_tag`/`refresh_token` 表并 `close_connection()`（解决绕过 run() 起服务缺表）。
  - `_issue_tokens` / `_resolve_token`（解析 JWT）/ `_rate_allowed`（IP 固定窗口限流）。
  - `_SECURITY_HEADERS` + `_cors_origin`（白名单回显，去通配符）+ `_emit_common_headers` 接入所有响应。
  - `login` 返回 `token`+`refresh_token`；新增 `refresh`(轮换吊销旧令牌)、`logout`(吊销刷新令牌)。
  - 配置全来自环境变量：`JWT_SECRET`(生产必设)、`ACCESS_TTL`、`REFRESH_TTL`、`RATE_LIMIT`、`RATE_WINDOW`、`CORS_ORIGIN`。
- `static/index.html`：`login()` 存 `refresh_token`；`api()` 在 401 时自动调 `/api/refresh` 续期重试一次（防雪崩 `refreshing` 标志）；`logout()` 调 `/api/logout` 吊销。
- `README.md`：新增「认证与安全（生产加固）」段落，含环境变量表与客户端约定，强调 `JWT_SECRET` 必须生产设置。
