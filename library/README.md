# 个人图书管理系统

一个基于 Python + SQLite 的图书管理系统，提供**命令行**和**图形界面（Tkinter）**两种操作方式，覆盖用户、图书、借阅、罚款、统计等完整业务。

## 功能清单

### 用户模块
- 用户注册（支持设置密保问题/答案）
- 用户登录 / 注销登录
- 余额充值、查询余额
- 修改登录密码
- 忘记密码（密保找回）
- 管理员查看全部用户（含权限校验，仅管理员可用）

### 图书模块
- 添加 / 修改（含分类）/ 删除图书
- 查看全部图书
- 模糊搜索（书名 / 作者）
- **高级组合搜索**（书名 + 作者 + 分类 + 借阅状态多条件叠加，可指定排序字段与方向）
- 按分类筛选、按分类统计
- 分页浏览图书
- 排序浏览（ID / 书名 / 作者 / 分类，升序 / 降序）
- 从 txt 批量导入图书
- 备份图书数据到 JSON / 从 JSON 恢复备份（覆盖或追加）
- **图书封面卡片预览**（选中图书即用 Canvas 绘制封面，含书名、作者、分类、状态角标）
- **图书详情窗口**（双击列表或点击封面打开：封面 + 基本信息 + 我的评分 + 读者评论 + 借阅历史 + 借阅/归还快捷操作）

### 借阅模块
- 借阅图书（默认借期 7 天）
- 归还图书（逾期按每天 0.5 元计算罚款，归还后自动推进预约队列）
- 续借图书（可自定义续借天数，逾期不可续借）
- 查看我的借阅记录 / 借阅统计
- 查看我的逾期图书
- **借阅到期提醒**（即将到期 3 天内 + 已逾期的图书，登录时自动提示，也可手动查看）
- 缴纳罚款（余额扣款，缴清后自动结清）
- 导出借阅记录到 txt / **CSV**（CSV 带 UTF-8 BOM，Excel 双击打开不乱码，管理员可导出全库记录）

### 借阅规则模块
- **借阅上限**：每人同时最多可借 N 本（默认 5 本，管理员可改）
- **逾期禁借**：存在逾期未还图书时，暂停借阅与预约权限
- **欠费暂停**：未结清罚款达到阈值（默认 10 元，管理员可改）时暂停借阅
- **借阅额度状态条**：实时显示「已借/上限、剩余、逾期、欠费」，异常时标红
- 规则参数存于 `config` 表，修改后立即生效，可一键恢复默认

### 图书预约模块
- **预约排队**：已被借出的图书可预约，实时显示排队位次
- **到书通知**：图书归还后，队首预约人自动变为「已到书」，登录时弹窗提醒
- **优先取书权**：已预约到书的读者享有优先权，其他人不能抢借该书
- **队列顺延**：取消预约或借阅完成后，名额自动顺延给下一位
- 支持查看任意图书的排队名单、我的预约列表、逾期或欠费用户禁止预约

### 标签模块
- **多标签管理**：与固定分类互补，一本书可打多个标签（如「入门」「面试必备」「经典」）
- **常用/热门标签快选**：编辑标签时可一键追加，也可手写逗号分隔
- **多标签筛选**（任一匹配 / 必须全部匹配两种模式）
- 标签管理（管理员）：查看使用统计、删除标签、批量清理未被使用的孤儿标签
- 自动去重、去空白、超长截断，单标签不超过 12 字

### 评分模块
- **图书评分与评论**（1~5 分 + 一句话评论，同一用户可覆盖修改自己的评分）
- 平均分与评分人数统计，星号可视化（★★★★☆）
- 图书详情页展示读者评论与好评榜
- 撤销自己的评分

### 操作日志模块（审计）
- **全流程留痕**：注册、登录、借阅、归还、续借、评分、预约、取消预约、充值、缴罚款均自动记录
- 记录内容：操作人、时间、动作、对象（如「《三体》#7」）、详情（如应还时间、罚款金额）
- **日志查询**（管理员）：按动作筛选，展示最近 500 条，支持一键清空
- 动作计数概览，快速了解系统使用情况
- 设计原则：写日志失败会被捕获，绝不影响主业务流程

### 统计模块
- 图书统计仪表盘（总数 / 已借出 / 在架）
- **数据可视化图表**（纯 Canvas 绘制的分类占比环形图 + 在架/借出堆叠柱状图，无第三方依赖）
- 排行榜（可切换「借阅次数榜」与「好评榜」）
- 图书分类统计
- 我的借阅统计概览
- **HTML 统计报告导出**（自包含单文件，浏览器打开即看，可「打印 → 另存为 PDF」存档；含概览卡片、分类占比条、借阅榜、好评榜、风控提示）

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `main.py` | 统一启动入口，选择命令行或图形界面模式 |
| `app.py` | 命令行版主程序（菜单交互） |
| `gui.py` | 图形界面版主程序（Tkinter） |
| `book.py` | 图书增删改查、搜索、统计、备份恢复 |
| `user.py` | 用户、余额、密码、密保相关操作 |
| `borrow.py` | 借阅、归还、续借、罚款、借阅历史与 CSV 导出 |
| `rating.py` | 图书评分与评论（独立维护 rating 表） |
| `rules.py` | 借阅规则引擎与参数配置（独立维护 config 表） |
| `reservation.py` | 图书预约排队与到书通知（独立维护 reservation 表） |
| `tag.py` | 图书标签体系（独立维护 tag / book_tag 表） |
| `log.py` | 操作日志审计（独立维护 operation_log 表） |
| `report.py` | HTML 统计报告生成 |
| `db.py` | 数据库初始化、建表、预置测试图书 |
| `library.db` | SQLite 数据库文件（首次运行自动创建） |

## 环境要求

- Python 3.7+
- 仅使用标准库（`sqlite3`、`tkinter`、`json`、`datetime` 等），**无需安装任何第三方依赖**

> 图形界面依赖 `tkinter`，Windows 官方安装包自带；Linux/macOS 若缺失可用系统包管理器安装（如 `sudo apt install python3-tk`）。

## 快速开始

```bash
# 统一入口（推荐）
python main.py

# 或直接启动命令行版
python app.py

# 或直接启动图形界面版
python gui.py

# 首次初始化数据库、导入预置图书并创建默认管理员（可选）
python db.py
```

首次运行会自动创建 `library.db` 并建表。运行 `python db.py` 会导入 **34 本预置图书**（覆盖 9 个分类），并创建默认管理员账号。

**默认管理员**：用户名 `admin`，密码 `admin123`（余额 100 元，拥有管理权限）。

## 数据库结构

- **user**：`id, username, password, balance, security_q, security_a, is_admin`
- **book**：`id, title, author, category, is_borrow`
- **borrow_record**：`id, user_id, book_id, borrow_time, return_deadline, return_time, penalty`
- **rating**：`id, user_id, book_id, score, comment, create_time`（`user_id + book_id` 唯一，一人一书一条评分）
- **reservation**：`id, user_id, book_id, reserve_time, status, notify_time`（`status` 取值 waiting / ready / done / cancelled）
- **config**：`key, value`（借阅规则参数，如 `borrow_limit`、`fine_threshold`）
- **tag**：`id, name UNIQUE`　**book_tag**：`book_id, tag_id`（复合主键，图书与标签多对多）
- **operation_log**：`id, user_id, username, action, target, detail, log_time`（username 为写入时的快照）

### 图形界面模式
启动后先登录/注册，主界面包含 4 个标签页：

- **图书管理**：左侧表单 + 高级搜索/标签筛选入口 + 右侧图书列表，最右侧为封面卡片；**双击列表任意图书**可打开详情窗口（含标签行与借阅周期时间线）
- **借阅管理**：借阅 / 归还 / 续借 / 查看逾期 / 🔔到期提醒；第二行为预约区（预约图书、我的预约、查看队列）与借阅额度状态条
- **个人中心**：充值、改密码、缴罚款、TXT/JSON/CSV 数据导出、管理员功能（查看用户、借阅规则设置、操作日志、标签管理）
- **统计报表**：仪表盘 + 环形图 + 堆叠柱状图 + 排行榜（借阅榜/好评榜可切换）+ 分类明细 + 导出 HTML 报告

## 说明

- 借阅规则：每本书借期 7 天，逾期后每天 0.5 元罚款。
- 借阅上限：默认每人同时最多借 5 本；管理员可在「借阅规则设置」中调整。
- 禁借条件：有逾期未还图书，或未结清罚款达到阈值（默认 10 元）时，暂停借阅与预约。
- 预约规则：仅「已借出」的图书可预约；归还后队首自动到书并弹窗提醒；已到书的读者享有优先取书权。
- 标签规则：标签是柔性分类，与「分类」互补；筛选时可选「包含任一」或「必须包含全部」。
- 借阅周期时间线：在图书详情窗口中以「借出 → 应还 → 归还」三节点展示，未归还会标红提示逾期。
- 到期提醒：登录后自动检查，3 天内即将到期或已逾期的图书会弹窗提示。
- 评分规则：1~5 分，可附一句话评论；同一用户对同一本书重复评分会覆盖旧记录。
- 罚款缴纳：在「个人中心」一键缴纳，自动从余额扣除并结清。
- 删除图书前会校验是否存在未归还借阅，避免误删。
- 默认管理员：`admin / admin123`（由 `python db.py` 创建）。
- 输入健壮性：命令行对所有数字输入做了校验，非法输入不会导致程序崩溃。
- 界面与图表全部使用 Python 标准库（`tkinter.Canvas`）绘制，不依赖任何第三方库。
- `rating` / `config` / `reservation` / `tag` / `book_tag` / `operation_log` 六张表由各自模块独立幂等创建，无需手动建表。
