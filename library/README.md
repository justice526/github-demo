# 个人图书管理系统

一个基于 Python + SQLite 的图书管理系统，提供**命令行**和**图形界面（Tkinter）**两种操作方式，覆盖用户、图书、借阅、罚款、统计等完整业务。

## 功能清单

### 用户模块
- 用户注册（支持设置密保问题/答案）
- 用户登录 / 注销登录
- 余额充值、查询余额
- 修改登录密码
- 忘记密码（密保找回）
- 管理员查看全部用户

### 图书模块
- 添加 / 修改（含分类）/ 删除图书
- 查看全部图书
- 模糊搜索（书名 / 作者）
- 按分类筛选、按分类统计
- 分页浏览图书
- 排序浏览（ID / 书名 / 作者 / 分类，升序 / 降序）
- 从 txt 批量导入图书
- 备份图书数据到 JSON / 从 JSON 恢复备份（覆盖或追加）

### 借阅模块
- 借阅图书（默认借期 7 天）
- 归还图书（逾期按每天 0.5 元计算罚款）
- 续借图书（可自定义续借天数，逾期不可续借）
- 查看我的借阅记录 / 借阅统计
- 查看我的逾期图书
- 缴纳罚款（余额扣款，缴清后自动结清）
- 导出借阅记录到 txt

### 统计模块
- 图书统计仪表盘（总数 / 已借出 / 在架）
- 热门借阅排行榜（Top N）
- 图书分类统计
- 我的借阅统计概览

## 项目结构

| 文件 | 说明 |
| --- | --- |
| `main.py` | 统一启动入口，选择命令行或图形界面模式 |
| `app.py` | 命令行版主程序（菜单交互） |
| `gui.py` | 图形界面版主程序（Tkinter） |
| `book.py` | 图书相关数据库操作 |
| `user.py` | 用户、余额、密码、密保相关操作 |
| `borrow.py` | 借阅、归还、续借、罚款相关操作 |
| `db.py` | 数据库初始化、建表、预置测试图书 |
| `library.db` | SQLite 数据库文件（首次运行自动创建） |

## 环境要求

- Python 3.7+
- 仅使用标准库（`sqlite3`、`tkinter`、`json`、`datetime` 等），**无需安装任何第三方依赖**

> 图形界面依赖 `tkinter`，Windows 官方安装包自带；Linux/macOS 若缺失可用系统包管理器安装（如 `sudo apt install python3-tk`）。

## 快速开始

```bash
# 统一入口（推荐）
python main.py

# 或直接启动命令行版
python app.py

# 或直接启动图形界面版
python gui.py

# 首次初始化数据库并导入预置测试图书（可选）
python db.py
```

首次运行会自动创建 `library.db` 并建表。如需示例图书数据，运行 `python db.py` 会导入 15 本预置图书。

## 数据库结构

- **user**：`id, username, password, balance, security_q, security_a`
- **book**：`id, title, author, category, is_borrow`
- **borrow_record**：`id, user_id, book_id, borrow_time, return_deadline, return_time, penalty`

## 使用示例

### 命令行模式
```
=====个人图书管理系统=====
1. 用户注册
2. 用户登录
...
29. 查看全部用户（管理员）
0. 退出程序
请输入功能编号：
```

### 图形界面模式
启动后先登录/注册，主界面包含 4 个标签页：图书管理、借阅管理、个人中心、统计报表。

## 说明

- 借阅规则：每本书借期 7 天，逾期后每天 0.5 元罚款。
- 罚款缴纳：在「个人中心」一键缴纳，自动从余额扣除并结清。
- 删除图书前会校验是否存在未归还借阅，避免误删。
